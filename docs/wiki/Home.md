# Wiki de TaskFlow

Bienvenido a la documentación técnica de **TaskFlow**, una app de tareas que demuestra:

1. **Contenerización con Docker** — 3 servicios orquestados con Docker Compose.
2. **Gestión de código con GitHub** — GitFlow, Pull Requests y CI/CD con GitHub Actions.
